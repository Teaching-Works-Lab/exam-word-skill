# 试卷生成踩坑清单与验收门禁

> **Exam Authoring Pitfalls & Acceptance Gates**
>
> **何时必读**：任务不是「把已有 Word/PDF 套模板」，而是**从题库 / 大纲 / 知识点出一份新卷、重组 A/B 卷、或调整既有试卷的题型与分值**时。本文件与 `modes.md`、`template-contract.md` 同为必读。
>
> **来源**：2026-11《智能制造装备》期末 A/B 卷实战复盘（三轮修订）。下面每一条都对应一次实际返工，不是理论推演。

## 0. 一条原则

> 结构化 JSON 是唯一内容源；DOCX 只是模板渲染结果；**只通过 OOXML 结构校验不算验收，必须渲染成 PDF 逐页检查分页**。

`verify_docx.py` 只能证明模板部件未被破坏，它**不会**发现「选项被分页拦腰截断」「题干半句跑到下一页」「（15 分）被拆成孤立的『分）』」。这类问题只有渲染后才可见。

## 1. 内容来源与方案对齐

| 坑 | 必做 |
|---|---|
| 误以为仓库里有现成试题 | `assets/reference.docx` 只是**格式模板**，仓库不存题目。题目来自用户题库 / 大纲 / 知识点，必须在对齐稿里写明真实来源 |
| 接到「出份试卷」就直接出终稿 | 先出**试卷明细对齐稿**让用户确认：考试性质（期末笔试 / 考查）、题型结构、各部分分值、卷数（A 卷 / A+B 卷）、是否含主观题 |
| 大纲考核方式与用户要求冲突 | 大纲写「考查」（无笔试）而用户要「期末笔试」时**明确提示**，并建议在课程考核方案里补一条笔试说明；不要默默改 |
| 卷头信息是占位值 | `school` / `academic_term` / `unit` / `teacher` / `exam_mode` / 考试时长都是占位值，交付时必须请用户确认，或在回复里显式标注 |
| 某教学单元题库 0 题 | 按大纲**新编**并在明细里逐题标「新编」，便于教师重点审核；不要跳过该单元 |
| 用户临时调整分值结构 | 客观题压缩后，被砍下的题不要丢：与题库余量重组为 B 卷，并校验 A/B **客观题、主观题均零重复** |

**方案对齐前不要调用 `build_from_spec.py`。** 对齐稿里应包含：依据材料、题库盘点、卷面结构表、逐题明细、单元/课程目标覆盖、待确认事项。

## 2. 题库清洗（生成前，不是生成后）

题库抓回来先做**全库过滤**，再抽题。真实案例：题库 453 题中 #249 是残题——题干混入整段方案描述、选项只剩 `A. 点移到` / `B. 点，无需毫米级精度)`、答案为空；它混进卷面后变成「第 8 题数据异常」。

```python
def bad(x):
    ans = (x['answer'] or '').strip()
    opts = [o for o in x['options'] if o.strip()]
    if x['type'] == '单选题':
        if len(opts) < 3: return '选项不足'
        if not re.fullmatch(r'[A-E]', ans): return '答案异常'
    elif x['type'] == '多选题':
        if len(opts) < 3: return '选项不足'
        if not re.fullmatch(r'[A-E]{2,5}', ans): return '答案异常'
    else:  # 判断题
        if ans not in ('正确', '错误'): return '答案异常'
    if len(x['stem'].strip()) < 8: return '题干过短'
    return None
```

还要做三项**体检并如实报告**：

1. **答案分布**：单选题若某个字母占比过高（实测 B 占 10/18 = 56%、D 为 0 道）、多选出现全选 `ABCD`，要提示用户。**不要擅自打乱选项**——重排后卷面答案字母会与平台上原题对不上；若要打散，用「循环移位」保留选项相对顺序，并说明题库序号对应关系随之失效。
2. **单元权重对照大纲**：新编热点题天然集中在某几个单元，容易把权重拉偏。明细里必须列出「大纲权重 vs 卷面实际」，偏差如实标注。
3. **答案隔离**：学生卷不得出现 `答案：` / `参考答案` / `评分要点` / `正确答案` 等字样；参考答案与评分标准**单独成文件**。

## 3. 得分表：分数行、得分行必须留空

> **与直觉相反**：卷首得分表是**阅卷教师填写并签字**用的，不是印给学生看的分值表。

- `score_table` 只填第一行「题号 / 一 二 三 四 五 / 总分」；**「分数」行和「得分」行（含总分格）全部传空串**。
- 各大题分值改印在**大题标题**里，例如 `四、简答题（共 4 题，每题 10 分，共 40 分）`，学生照样看得见分值。
- `metadata.summary` 仍可写「满分 100 分；考试时间 120 分钟」。

```json
"score_table": [
  ["题号", "一", "二", "三", "四", "五", "", "总分"],
  ["分数", "", "", "", "", "", "", ""],
  ["得分", "", "", "", "", "", "", ""]
]
```

`_populate_score_table()` 会把未指定的单元格清空，所以**不传 `score_table` 也会清空**；但显式传空串更不容易被模板里的旧值误导。注意 `modes.md` 与早期测试里的 `["分数","40","60","100"]` 只是验证 builder 行为的样例，**不是命题规范**。

## 4. 分页与段落控制（最容易返工的一节）

### 4.1 spec 段落控制字段

`build_from_spec.py` 的 `_configure_paragraph()` 支持以下可选字段（**`modes.md` 早期版本未记录**）：

| 字段 | 作用 | 典型值 |
|---|---|---|
| `keep_next` | 与下一段同页（`w:keepNext`） | `true` |
| `keep_together` | 段内不分页（`w:keepLines`），防长题干半句跨页 | `true` |
| `left_twips` | 整段左缩进（twips） | `question` 默认 283，`option` 默认 425 |
| `first_twips` | 首行相对缩进（负值 = 悬挂） | `question` 默认 -283 |
| `before_pt` / `after_pt` / `line_pt` | 段前 / 段后 / 行距 | `spacer` 用 `after_pt` 撑答题空白 |
| `align` | `left` / `center` / `right` | — |

`_add_block()` 里 `question` 默认 `{left_twips: 283, first_twips: -283}`（题号顶格、正文从 283 起），`option` 默认 `{left_twips: 425}`。**block 自带同名字段会覆盖默认值**，这正是做小问缩进的入口。

### 4.2 断页三条规则

1. **一道题不可分割**：题干加 `keep_next`，除**最后一个选项外**所有 `option` 加 `keep_next`，使「题干 + 全部选项」成为同页块。否则会出现第 1 页题干 + 前两个选项、第 2 页页首孤零零 `C.` / `D.`。
2. **判断题是例外**：判断题**没有选项**，若给题干加 `keep_next`，14 道题会连锁绑成一大块，反而制造大片留白。判断题只加 `keep_together`。
3. **长题干段内不分页**：多行题干要加 `keep_together`，否则会出现「…铣削」在第 5 页末、「)。( )」在第 6 页首。

### 4.3 中文断行与分值残片

- 题干末尾的 `（15 分）` 会被中文断行拆成「（15」+「分）」，在页底留下孤立残片。**不要**在题干里重复写分值——大题标题已声明，直接从源数据删掉。
- 若确实需要保留分值标注，用不换行空格 `\u00a0` 连接数字与「分」；根治办法仍是删除冗余标注。

### 4.4 小问必须逐行显示

`（1）…（4）`、`①…⑤` 这类编号小问**不能挤在一个段落里**，教师要的是「一行一个小问、有缩进、与题干对齐、看着舒服」。

```python
ITEM_MARK = re.compile(r'（\d+）|[①②③④⑤⑥⑦⑧⑨⑩]')

def split_items(text):
    marks = [m.start() for m in ITEM_MARK.finditer(text)]
    if not marks:
        return [text.strip()]
    parts = []
    if marks[0] > 0:
        parts.append(text[:marks[0]].strip())
    for i, st in enumerate(marks):
        en = marks[i + 1] if i + 1 < len(marks) else len(text)
        parts.append(text[st:en].strip())
    return [p for p in parts if p]
```

要点：

- 只认**纯数字括号编号**与圈号；`（各至少 3 点）`、`（至少 4 类）`、`（喷嘴/热床温度…）` 这类说明括号**不能误拆**。
- 引导句（「请完成：」）单独一段，加 `keep_next` 绑定第 1 小问。
- 每个小问一个独立 `question` block，带 **`left_twips: 425, first_twips: -142`**：首行起点 `425-142=283` 与题干正文对齐（不顶格），回行从 425 起形成悬挂缩进。
- 各小问加 `keep_together`（段内不分页）；**中间小问不要加 `keep_next`**（会连锁造成留白）；最后一个小问加 `keep_next` 绑定答题空白。
- 试卷明细 Markdown 同步一行一个小问（用全角空格缩进），与卷面保持一致。

### 4.5 显式分页与答题空白

- `pages[]` 每多一项就插入一个硬分页符。**不要按题目逐条分页**：客观题连续排版让其自然流动，按题型分块即可（实测 5 个 spec page 得到 7 个物理页，比 10 个硬分页干净）。
- 答题空白用 `{"type":"spacer","text":"","after_pt":N}`。**小问拆行后题干占高增加，必须同步收敛 `after_pt`**（例：简答 200→190、综合 480→420），否则整块连同空白会被挤到下一页。
- 拆行后总页数、断页数要重新检测，不能沿用上一版结论。

## 5. 渲染验收（不可跳过）

按顺序执行，任一步失败都要回到 spec 重排：

1. `python scripts/verify_docx.py <out.docx> assets/reference.docx` → `valid: true` 且 `preserved_parts_match: true`。
2. **内容门禁**（按 spec 逐条比对 DOCX 段落文本）：题干数、选项数零缺失；得分表数值全空；无答案泄漏关键词；无 AI 生成痕迹（注意「大语言模型」是**题目内容**不是生成痕迹，别误报）。
3. LibreOffice 渲染 PDF → PyMuPDF 逐页提取文本：
   - 页首是否为孤立选项行 `^[A-E][\.、．]`（应为 0 页）
   - 题干是否跨页断裂（页首残句是某题干的尾部，应为 0 处）
   - 页末是否有长度 ≤4 的残片（「分）」「行」）
   - 页首是否为孤立小问编号
   - **过滤页脚**（`第 N 页 / 共 N 页`）后再判断正文首行
4. 渲染关键页 PNG 做视觉复核：卷头、得分表、小问逐行排版、答题空白是否充足。
5. 交付前确认：A/B 卷题目零重复；明细答案序列与试卷逐题一致；单元权重与大纲对照已标注。

## 6. 常见诱惑 → 必选动作

| Temptation | Required choice |
|---|---|
| 只跑 `verify_docx.py` 就交付 | 渲染 PDF + 逐页断页检测 + PNG 视觉复核 |
| 把小问连成一整段省事 | 按编号拆成独立段落，缩进对齐 |
| 给所有题干统一加 `keep_next` | 判断题不加；只给有选项的题与末小问加 |
| 卷首得分表印上 36/20/14/… | 分数行、得分行全部留空，分值写进大题标题 |
| 题干末尾再写一次「（15 分）」 | 删掉，避免中文断行残片 |
| 题库直接抽题不看质量 | 先全库过滤残题，再体检答案分布与单元权重 |
| 发现答案分布偏斜就打乱选项 | 先报告用户；重排会破坏与平台原题的对应 |
| 只改 DOCX 不回写 spec | spec 是唯一内容源，所有改动在 spec/生成器里做 |

## 8. A/B 平行卷去重（双卷场景，2026-11-24 新增）

平行卷只做到「题干不完全相同」是不够的。同一门课、同一份大纲，考点必然有交集；真正要拦的是三种重复：**同一道题换种说法**、**参考答案可以互相套用**、**两卷压在同样两个单元**。

### 8.1 检查项与阈值

| 层级 | 检查 | 阈值 | 为什么 |
|---|---|---|---|
| 题干 | 精确相同（去空白 / 标点后） | 0 容忍 | 直接泄题 |
| 题干 | 近似相似度（`difflib`） | < 0.60 | 防「换种说法」 |
| 选项 | 选项组合完全相同 | 0 容忍 | 改题干不改选项 = 同题 |
| 答案 | 客观题答案序列完全相同 | 0 容忍 | 序列雷同，蒙题有规律 |
| 主观题 | **参考答案**相似度 | **< 0.35** | 最关键：背一套答案不能通吃两卷 |
| 主观题 | 题干相似度 | < 0.60 | 同上 |
| 单卷 | 卷内重复 | 0 容忍 | 本卷自己的低级错误 |

### 8.2 门禁代码（放在组卷脚本末尾、构建 DOCX 之前）

```python
import difflib, html, re

def _n(s):
    return re.sub(r'[\s，。、（）()：:；;「」『』【】,.]', '', html.unescape(s or ''))

def _sim(a, b):
    return difflib.SequenceMatcher(None, _n(a), _n(b)).ratio()

STEM_LIMIT, ANSWER_LIMIT = 0.60, 0.35

for a in obj_a:
    for b in obj_b:
        assert _n(a['stem']) != _n(b['stem']), '客观题题干重复'
        assert _sim(a['stem'], b['stem']) < STEM_LIMIT, '客观题题干近似重复'
assert set(tuple(q['options']) for q in obj_a if q['options']).isdisjoint(
       set(tuple(q['options']) for q in obj_b if q['options'])), '选项组合重复'
assert ' '.join(x['answer'] for x in obj_a) != ' '.join(x['answer'] for x in obj_b), '答案序列相同'

max_ans = max(_sim(a['answer'], b['answer']) for a in SUBJ_A for b in SUBJ_B)
assert max_ans < ANSWER_LIMIT, f'主观题参考答案可套用（{max_ans:.2f}）'
```

门禁必须打印量化结果留档，否则「零重复」只是一句口头承诺：

```text
[去重门禁] 客观题 18×18 对：题干/答案序列/选项组合 0 重复
[去重门禁] 主观题 6×6 对：题干最高相似 0.19｜参考答案最高相似 0.16
```

### 8.3 最容易漏的三类「软重复」

1. **综合应用题同题化**：两卷综合题都写「某设备采集多源数据，请设计诊断流程」，参考答案都会落到特征工程、混淆矩阵、迁移学习、模型漂移、可解释性——文本相似度可能只有 0.38，但**考点是同一套**，学生背一份要点即可通吃。处理：两卷综合题换**不同装备载体 + 不同命题角度**（如 A 卷「FDM 工艺质量追溯」、B 卷「数控机床精度与热误差伺服」）。
2. **多选题引导句撞车**：两道多选都写「关于 X，下列说法正确的有（ ）」，`difflib` 会给到 0.5+。这不是重复，但会让人误判、也让门禁数字难看。处理：换引导句式（「下列判断合理的有」「在……场景中，下列做法恰当的有」）。
3. **热点题两卷各来一套**：大模型、数字孪生、PHM 在两卷都出主观题，答案必然高度重合。处理：热点**分工**——A 卷主观题走新技术（大模型 / 孪生 / PHM），B 卷主观题走装备本体与控制（精度 / 伺服 / 柔性 / 信号链），热点通过**客观题**在两卷都保留。

### 8.4 改完 B 卷要复查的三件事

- 单元分值分布会变（组卷脚本自动重算），确认两卷**互补覆盖**六单元，而不是某单元两卷都为零；
- 明细里的「单元与课程目标覆盖」表和「分布提示」要随新题自动更新，不要留旧结论；
- 参考答案必须与卷面**同源重生成**，不能只改卷不改答案。
